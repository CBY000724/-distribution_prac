# 네가 있어 따뜻했던 날들

첨부 이미지 위에 마음을 전하는 편지를 띄우는 HTML 카드입니다. 편지 문단이 위에서 아래로 차례대로 나타나고, 배경에는 하트와 금빛 빛줄기가 은은하게 움직입니다.

## 사용 방법

1. `letter-card.zip`의 압축을 풉니다.
2. `index.html`과 `companion.jpg`가 같은 폴더에 있는지 확인합니다.
3. `index.html`을 Chrome, Edge, Safari 같은 브라우저에서 엽니다.
4. **음악 켜기**를 누르면 잔잔한 멜로디가 반복 재생됩니다. **음악 끄기**를 누르면 멈춥니다.

인터넷 연결이나 별도 프로그램 설치 없이 열 수 있습니다. 화면이 좁으면 이미지가 위쪽에 보이도록 편지를 아래에 배치합니다. 기기에서 동작 줄이기 설정을 켜면 애니메이션 없이 편지가 표시됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 편지 문구, 반응형 디자인, 애니메이션, 음악 재생 코드 |
| `companion.jpg` | 카드 배경에 사용한 첨부 이미지 |

## 카드 수정하기

- **편지 문구**는 `index.html`을 텍스트 편집기로 열고 `<article class="letter">` 안에 있는 `<h1>`과 `<p>`의 내용을 바꾸면 됩니다. 브라우저 탭 제목도 바꾸려면 `<title>`을 수정하세요.
- **배경 이미지**는 같은 폴더의 `companion.jpg`를 다른 JPG로 교체하면 됩니다. 다른 이름이나 확장자를 사용한다면 HTML 안의 `url("companion.jpg")`도 변경하세요.
- **카드를 공유할 때**는 HTML과 이미지 두 파일을 같은 ZIP으로 묶어 보내면 됩니다.
